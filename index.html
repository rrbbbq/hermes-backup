Hermes Backup

Encrypted backups for a personal Hermes VPS, stored in the owner's Google Drive using rclone.

Purpose

Hermes Backup is a private backup and recovery tool operated by its owner for their own Google account. It stores encrypted backup archives and checksum files, and supports restoring those backups. It is not a public service and does not accept sign-ups.

Google Drive access

The app requests only the https://www.googleapis.com/auth/drive.file permission. In this rclone setup, it creates and manages its own backup files and folders: uploading, listing, downloading, updating, and deleting them as needed for backup and recovery. It does not request access to all files in Google Drive.

Your data

Backup data is used only for the owner's backup and recovery. It is not sold, used for advertising, or shared with unrelated parties. This informational website does not handle Google sign-in, OAuth tokens, or backup files.
