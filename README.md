# Hermes Backup

Static OAuth branding pages for a personal, non-commercial rclone Google Drive backup app using `drive.file`.

## Google Auth Platform Branding

- App name: `Hermes Backup`
- Application home page: `https://rrbbbq.github.io/hermes-backup/`
- Application privacy policy link: `https://rrbbbq.github.io/hermes-backup/privacy.html`
- Authorized domain, if required: `rrbbbq.github.io` (no scheme or path)

Use these values only in the Hermes Backup Google Cloud project. The existing Gangneung rclone project is independent and must remain untouched.

## Hosting

GitHub Pages: deploy from `main`, `/(root)`. No custom domain, build dependencies, scripts, cookies, analytics, or external assets. This repository contains public informational pages only; never add credentials or backups.

Personal use publishing is distinct from Google brand verification. The pages do not guarantee Google approval. Keep the website's statements accurate if the app's data handling or scope changes.
